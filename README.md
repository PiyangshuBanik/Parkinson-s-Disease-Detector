# 🧠 Parkinson's Disease Detection System

A Machine Learning-based system to detect Parkinson’s Disease using biomedical voice measurements and data analysis.

---

## 📌 Project Overview

Parkinson’s Disease is a progressive neurological disorder that affects movement and speech.
This project aims to build an intelligent system that can **predict Parkinson’s Disease at an early stage** using machine learning algorithms.

---

## 🚀 Features

* 🔍 Early detection of Parkinson’s Disease
* 📊 Data preprocessing and feature extraction
* 🤖 Machine Learning model training and prediction
* 📈 Accuracy evaluation and performance metrics

## 📊 Dataset

The dataset contains biomedical voice measurements used to detect Parkinson’s Disease.

* Features include: vocal frequency, jitter, shimmer, etc.
* Target: 0 (Healthy), 1 (Parkinson’s)

---

## 📈 Model Performance

* Accuracy: 92.31%
* Precision: 93.33%
* Recall: 96.55%
